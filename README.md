# Aminul Huq — Academic Website

This is a static GitHub Pages website inspired by an editorial academic layout, with the information architecture of a researcher portfolio.

## Publish

Upload the **contents of this folder** to the root of `aminul-huq/aminul-huq.github.io`. Keep `index.html` at repository root.

## Profile photo

The site uses `assets/images/Aminul.png` for the profile photo. Keep your existing `Aminul.png` file in that folder when uploading this update.

## Publications

The publication page is labeled **Selected Publications** and links to Google Scholar for the complete list. Selected research on the homepage is in `index.html`. Entries are ordered newest to oldest.

## Styling

Edit `assets/css/style.css`. The main accent is `--accent: #245a8d;` near the top of the file.
